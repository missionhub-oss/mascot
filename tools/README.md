# 制作工具（规划中）

> [!NOTE]
> 当前仓库处于 **v0.1 草稿样稿阶段**，`tools/` 目录预留给后续陆续发布的吉祥物制作与自动化检验工具。

## 规划方向

后续计划围绕社区各 IP 形象的 `static/`、`animated/` 与 `manifest.json` 标准结构，陆续发布以下开源工具：

| 规划工具 | 目标用途 | 当前状态 |
| --- | --- | --- |
| 1:1 规格与元数据校验脚本 | 自动检查各角色 `static/` 与 `animated/` 中每张图片是否为严格 1:1 比例，并核验 `manifest.json` 与 Markdown 链接 | 规划中 |
| 多平台表情包打包导出脚本 | 基于 `manifest.json` 自动缩放与导出适用于微信、飞书、Telegram、Discord 的 1:1 规格与透明背景版本 | 规划中 |
| 角色视觉参考与提示词模板 | 提供标准色板文件（ASE / GPL）、上 M 下 H 矢量徽章源文件与角色一致性绘制指南 | 规划中 |
| 简易表情包文字合成工具 | 统一底栏粗黑红影描边排版，帮助社区成员快速制作新梗图并保持风格一致 | 规划中 |
