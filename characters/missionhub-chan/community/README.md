# 社区二创作品区（MissionHub 娘）

欢迎开源社区的朋友围绕 **MissionHub 娘（M 娘 / MH 娘）** 开展二次创作，并将作品贡献回本仓库与大家共享。

## 收录范围

- 全新主题的 1:1 静态或动态表情包（如 QEMU、RISC-V、Rust、硬件点亮、社区活动限定等）
- 同人插画、壁纸、社区头像、横幅与贴纸设计
- 不同画风或比例的衍生设定（正比立绘、像素风、简笔画、矢量图标）
- 动态表情（GIF / APNG / WebP）、Live2D 或 3D 模型源文件

## 目录组织规范

提交社区二创作品时，请在本目录下按 GitHub 用户名与作品短名称创建独立目录，同样按静态与动态分目录存放：

| 路径 | 说明 |
| --- | --- |
| `<github-username>/<work-slug>/README.md` | 作品简介、作者署名、创作灵感、使用工具与改编说明 |
| `<github-username>/<work-slug>/static/` | 静态作品与静态表情包（表情包图保持 1:1 正方形） |
| `<github-username>/<work-slug>/animated/` | 动态作品与动态表情包（表情包图保持 1:1 正方形） |
