依据 [Apache License 2.0](../LICENSE) 第 4 条，当您再分发原始素材或包含这些素材的衍生作品时，须履行以下开源协议义务：

1. **附带许可证副本**：随分发内容附带 [Apache License 2.0](../LICENSE) 完整文本或清晰的许可证链接。
2. **保留版权与归属声明**：完整保留原始版权声明及根目录 [`NOTICE`](../NOTICE) 文件中的归属说明。
3. **标注修改说明**：如果您对原图进行了裁切改字、重绘或结构修改，请在衍生作品说明中明确注明内容经过修改，以便下游使用者区分原版与二创版本。

## 4. 社区善意使用与尊重原则

在遵循开源协议自由精神的同时，社区倡导所有创作者与使用者秉持友善、尊重的开源文化：

- **尊重原型与社区成员**：MissionHub 娘的设计灵感部分源自团队成员 River 的真实性格与剑道特质。开展二次创作时请保持善意与分寸，避免将角色用于针对现实人物或社区成员的冒犯、调侃或不当联想。
- **维护健康正向的表达环境**：请勿将吉祥物形象用于违法违规内容、仇恨歧视、恶意攻击、虚假宣传或低俗不良场景。
- **标明版本与出处**：当前素材处于 v0.1 草稿样稿阶段，引用设计规范或二次加工时建议附带仓库链接，方便更多人找到最新版本与完整授权信息。

## 5. 二次创作视觉一致性建议

二次创作享有充分的艺术自由，不限制画风、比例或服饰演变。如果您希望作品能让社区朋友一眼认出是 **MissionHub 娘（M 娘 / MH 娘）**，建议优先保留以下视觉锚点中的若干核心要素：

| 优先度 | 核心视觉锚点 | 说明 |
| --- | --- | --- |
| 核心识别 | 上 M 下 H 红底白边徽章 | 佩戴在蝴蝶结中央、胸口或服饰显眼处 |
| 核心识别 | 右侧高马尾 + 红黑挑染 + 头顶弧形呆毛 | 构成角色最鲜明的剪影轮廓 |
| 推荐保留 | 使命红（`#E00818`）与炭黑（`#282828`）主配色 | 传递热血朝气与剑道风格对比 |
| 推荐保留 | 剑道服（红道服白衬领 + 黑剑道袴）与竹刀 | 体现剑道文化底色与迎难而上的气场 |
| 自由发挥 | 表情、姿势、主题道具与技术梗文案 | 鼓励结合更多开源项目、硬件板卡与节日主题自由拓展 |

完整色彩参数与元素拆解请参阅 [IP 设定与视觉元素说明](ip-guide.md)。

## 6. 关于表情包中的第三方开源元素

首批开发者表情包（`v0.1-dev-pack`）出于工程师文化致敬与幽默表达，在个别画面中融入了开源社区广为熟知的标志性元素：

- **Linux / Tux 企鹅**：出现于 `12-kernel-panic.png`、`13-read-dmesg.png`、`14-driver-start.png`。
- **Zephyr 名称标识**：出现于 `15-dts-trouble.png`、`16-kconfig-off.png`、`17-west-build.png`。
- **Yocto 名称标识**：出现于 `18-bitbake-wait.png`、`19-cache-gone.png`、`20-one-line-rebuild.png`。

上述第三方项目名称、标识与形象的权益均归各自权利人所有（详见 [`NOTICE`](../NOTICE)），本仓库的 Apache 2.0 授权不涵盖这些第三方商标权。若您在商业周边或对外品牌宣传中复用含第三方标识的单张贴纸，请同时自行确认对应项目的商标使用政策；若仅需纯粹的 MissionHub 娘形象，可优先选用不含第三方标识的贴纸或进行相应替换。
